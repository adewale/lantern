How to use lantern

Lantern explains code with animation you can step through. A scene is a sequence of named steps; every step has a link, an SVG frame, a plain-text frame and a JSON trace of the state it explains. A zero-dependency engine renders it all to SVG, in this page or in the Worker behind it.

Agents: curl / returns a plain-text guide, also at /llms.txt.

?scene=NAME&step=STEP opens a scene at a step, ?t=12.5 at a time. The address bar follows playback, so it is always a link to what is on screen.

02 Fetch

Every scene is an HTTP API: plain GET, no auth, CORS open. scene is a name; step is a step name (the frame as that step begins) or t is seconds; with neither you get the final frame. w sets the SVG width in px (default 1280). These examples follow the player above.

  • all scenes/index.json
  • steps & timing/index.json?scene=lantern
  • state per step/trace.json?scene=lantern
  • frame as SVG/frame.svg?scene=lantern&step=layout&w=640
  • frame as text/text?scene=lantern&step=layout
  • by time/text?scene=lantern&t=3

Errors are JSON: 404 { error, scenes } for an unknown scene, 404 { error, steps } for an unknown step, 400 for a bad t or w; each carries help: "/llms.txt".

04 Author

A scene is a class with an async construct(). this.step(name) marks a step; this.state is what traces record.

import { Scene, Labeled, Rectangle, Text, FadeIn }
  from '../src/index.ts';

export class Cache extends Scene {
  async construct() {
    this.state = { cache: false };
    await this.step('before');
    const db = new Labeled(
      new Rectangle({ width: 2, height: 1 }), new Text('D1'));
    await this.play(new FadeIn(db));
    await this.step('after');
    this.state.cache = true;
  }
}

Or write it as data: sceneFromDoc(doc) plays a JSON doc of nodes, edges, code and step ops (docs/DOC-FORMAT.md).

sceneFromDoc({
  title: 'Counter',
  nodes: { n: { kind: 'state', label: '0', at: [0, 0] } },
  state: { n: 0 },
  steps: [{ name: 'inc', ops: [{ set: { n: 1 } }, { indicate: 'n' }] }],
})

Register it in scenes/index.ts, then:

npm run dev                 # live player, reloads on save
npm run see -- NAME STEP    # a frame as text + the state diff
npm run shot -- NAME        # contact sheet PNG of every step
