# Independent preservation review: engine_core

Read-only review of final diff against origin/main in fonts, graphing, lineage, perf and property tests. I did not author those changes. Reviewed changed assertions and the relevant VMobject split/insert/length and perf producer implementations. No edits to tests/source, test runs or mutations performed by this review.

## Verdict

No blocking preservation defect found. Existing proof was strengthened or moved to a cheaper independent keeper. Two remaining coverage limits are recorded below; they are not evidence that removed proof was lost.

- **Cubic geometry:** replacement reads original Float32 controls and evaluates Bernstein independently of pointOnCurve, replacing the old subject-generated dense sample/nearest-distance oracle. Count and exact first/last anchors remain. Per-source anchor boundary discovery plus final output-consumption assertion covers multiple source curves without copying the production split-allocation rule. The separate Manim fixture remains the allocation authority. splitCurve directly tests selected first/middle/last curve, equal parameter spans, exact anchors and untouched neighboring controls. The tolerance tightens old 3e-3 sampling resolution to 1e-5 for bounded controls in [-2,2]; it has not been widened to conceal an observed failure. Float32 convex control rounding explains an error allowance, though the comment is qualitative rather than a formal accumulated rounding bound.
- **Arc lengths:** independent eight-segment Bernstein arithmetic matches the documented approximation and checks each curve length plus total across disconnected subpaths. No analytic-arc-length promise is invented. Coverage limit: its generated subpaths each contain one curve, so an arcLength implementation counting only the first curve of each subpath could escape this new property. Existing multi-curve geometry tests do not independently prove that total-length traversal; a future multiple-curves-per-subpath row would improve this without blocking preservation of old coverage.
- **UTF-16:** generated astral symbols broaden the prior domain. Explicit `😀a` cluster [2] pins the actual UTF-16 offset, avoiding code-point-versus-code-unit ambiguity. Existing monotonicity, whitespace and bounded-index assertions remain.
- **Zero runtime:** new frames.length>1 prevents the old slice(1) loop passing vacuously. Expected SVG now comes from independently authored shifted Rectangle geometry, not the same completed scene under test. Existing all-finished-frame assertion remains.
- **Nested replacement:** count keeper remains and target/source render IDs now independently establish correct object ownership; the same count with the wrong shapes can no longer pass.
- **Perf:** wall-clock busy loops replaced by externally controlled performance.now with exact total/self semantics; production Perf is not mocked. Return identity, exception identity, subsequent stack cleanup, depth event selection, aggregation existence, counters/reset/disabled behavior and sequential begin/end are observed publicly. Timers are restored by Node's per-test mock context; try/finally disables and resets perf. No nested async self-time promise is invented. Coverage limit: new trace selection checks event names, not ts/dur units; existing removed busy-loop proof never checked those fields either.
- **Graphs:** fixed lineGraph keeper expanded to all ordered anchors including duplicates. Existing discontinuity split example remains separate. New affine c2p expectation independently checks shear/translation rather than relying only on inverse agreement; inverse and NumberLine endpoint tests complement it. Rotated area checks baseline closure and actual sample endpoints; bar interpolation fixes baseline and tests top coordinates against independent linear data values. Plot samples count is explicit and exact integer/unit-scale bounds avoid arbitrary tolerance. Existing authored numeric ticks/ranges, fixed graph examples, motion and byte-identical seeks remain.
- **Removed fixed repetition:** wrapping Text in Group during Write moved out of generated shape/lag cases into one dedicated full-frame comparison; it still runs both independently authored scenes and compares every frame. The random Create flat-versus-nested proof remains. Running the invariant fixed Text comparison twenty times never supplied additional inputs.
- **Fonts:** title now describes the fallback-scale assertion actually made. Fallback face order, missing-glyph collection, mixed run advance/cluster and combining-mark proofs remain.
