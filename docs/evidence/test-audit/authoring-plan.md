## Keepers and layers

1. Keep cheap value properties for normalization, escaping, palette contrast, timestamp carry, ordering, validation and cache names. Independent oracles already valuable: WCAG arithmetic, exact SHA-256 prefix, independent LCS forward DP and VM execution after escaping. Keep curated historical float32, SVG closepath, raw-template and ownership-cycle regressions as stable witnesses.
2. Keep native Diagram and panel behavior properties for semantic ownership, visible styles, geometry, scene cleanup, focus/morph handoffs and full-label fitting. These exercise public authoring behavior that a trace-only model cannot establish. Keep all seeded check gates: their exact diagnostic proves the intended failure rather than any error.
3. Keep source-built CLI/transcript/description fixtures and installed npm package smoke. The former owns source/ESM interoperability, engine alias identity, hashes and licences; the latter owns package exports/assets and absent-peer failures. Mocked resolver fixtures do not prove shipping files. The browser/real Mermaid fixture lanes separately establish real import and display compatibility.
4. Keep one miniature real FFmpeg lifecycle integration, conditional on explicit video tooling, and the installed invocation boundary. Generate pure WebVTT/timing inputs cheaply; do not export hundreds of random videos. Video test skipping must remain explicit in reporting.

## Highest confidence assertion repairs

- share:104: require two dimension failures with page-specific expected messages; `.every` on an empty array is vacuous. Test independent required metadata literals, including og:type, so shortening CARD_TAGS cannot erase coverage.
- helpers:208: permit only documented snapshot refusal; rethrow unexpected TypeError or unrelated errors. The current catch-all can conceal the validator defect this test is meant to expose.
- describe:44: match missing snapshot error/spec; bare assert.rejects is an unrelated-failure oracle. describe:10: independently compare complete changed-key sets, not just values of keys the subject returned.
- panels:365/380/393/434/453/471/494/507: guaranteed-valid inputs must be accepted. tryCard currently swallows no-room and returns from positive checks. Keep separately generated narrow/invalid-domain refusal checks. A selective rejection mutation must fail.
- caption positive properties:47/56/66/101/112: build bounded fitting captions and require success. Broad generated captions may legitimately exceed four lines, but that must not make all positive evidence disappear. Preserve wide-word and fifth-line refusal properties.
- panels:293: assert actual visible success/failure colors; mark kinds and two children do not prove the title's color claim. panels:234: assert vertical on-stage contract, or correct the title if only horizontal placement is promised; do not silently shrink the region generator.
- video:27: assert the independently normalized caption survives a cue payload round trip. Counting cue blocks permits deleting the text while retaining one cue.
- diagrams:746: deterministic covering plans should establish generator shape/flag coverage. Randomly observing all 21 forms in 300 plans is an avoidable statistical failure and should not be confused with a product property.

## Public and sibling surfaces

The stage API has named regions, custom boxes, heading/style adoption, native overlays and generated diagrams. Direct Diagram tests are not enough for stage ownership: keep stage adoption, clear/hide/reveal description and persistent walk evidence. Description JSON, terminal see output, no-JS transcript and site llms summary are distinct sibling views; agreement can be checked metamorphically, but at least one independently invented exact descriptor must remain. TypeScript consumers, runtime exports and npm-installed imports are different public surfaces; export allowlists are a false-positive static-data suspect until a deliberate API change is agreed.

SVG import fixtures own measured width, baseline, rotated text and closepath semantics. Topology-only minimal snapshots must not replace those import contracts. Share synthetic PNG headers correctly test a header-reading validator; the rendered preview test independently decodes and checks real 16:9 content inside 2:1 paper bands.

## Cost and ownership

This lane has 3,310 test LOC across 11 files, 149 declaration sites; the campaign total is 17,188 test LOC plus 1,520 support LOC. Shared random-snapshot.ts is 292 LOC; its plan/materialization boundary is the best place to avoid unnecessary glyphs without teaching tests a second Diagram implementation. tools/explain-package-smoke.ts has 144 LOC and proves archive composition independently of root imports. Video QA is owned by package.json's optional videos pipeline, test/explain-video.test.ts and tools/lib/explain-video.ts. Keep support changes small and owned: no generic test framework, no duplicate reader/importer, no new production export solely for testing.

Large scale probes protect prior algorithmic behavior; shared-host wall-clock budgets are noisy. Prefer stable independent allocation/operation evidence when naturally available, but do not add monkeypatches that assert private call shapes. Do not delete large probes merely because smaller PBT runs faster.
