# Author onboarding examples — 30 October 2026

This review covers the **source-gallery examples**, not the deployed six-explainer website export. `hello-world` has one case and one step; its complete nine-line source (changing only the repository import to the package import) is printed in [`docs/TUTORIAL.md`](../TUTORIAL.md#0-hello-world). `feature-tour` has 15 setting cases, each with a code-recipe step followed by the actual result. Its [guide](../FEATURE-TOUR.md) links specialized features that need separate capture/setup; 15 cases are **not** an exhaustive listing of Rayner's exports.

Checks run on the built sources: `npm run check`, `npm run demos:build`, `npm run demos:check`, `npm test` and `npm run test:embeds`. The build covers **32** scenes, **164** cases and **162** diagrams. The targeted `rayner review` receipts report 1 case / 2 step-width checks for Hello World and 15 cases / 60 step-width checks for the tour at 390 and 1180 px; every tour case reported **zero** phone labels below 12 px. Four representative resting frames—Hello World at 390 px; the steps and settings recipe panels at 390 px; the state recipe and result at 390 px—were opened and read. No animation-boundary screenshot was used as a resting-step witness.

`test/explain-onboarding.test.ts` asserts that the printed minimal source matches the real source except for its package import, that every declared feature has both a pictured author-side code excerpt and a result, and that the state-view case ends with count 1. `test/explain-fidelity.test.ts` checks the per-case step state. The HTML outputs are pinned separately on macOS and Linux in `test/lettering-baseline*.json`; all 30 previous entries stayed unchanged. Linux's diagram-bearing tour page has a distinct platform output pin, while Hello World's HTML bytes match macOS. These checks establish reproducibility and rendering, **not** that an unfamiliar author can copy every recipe successfully or that a reader has understood every feature. Do not call the tour exhaustive or add either example to the public website without a separately reviewed export and served-reader check.
